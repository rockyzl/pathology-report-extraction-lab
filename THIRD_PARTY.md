# Third-party data, models and attribution

This repository contains code, aggregate results and a small number of short report excerpts. It does not redistribute the raw report corpus, the clinical matrix or the cached per-report LLM responses: `data/raw/`, `data/derived/`, `results/cache/` and `results/extractions/` are gitignored. `scripts/build_data.py` fetches every input and verifies it against the SHA-256 recorded in `data/manifest.json`. It copies the file from a local sibling checkout when one exists and downloads it otherwise.

The results shown here are based upon data generated by the TCGA Research Network: https://www.cancer.gov/tcga.

The data are public, de-identified research data. They are not protected health information (PHI) or EHR data. This project is for research and education only. It is not a clinical tool and has no clinical validation.
